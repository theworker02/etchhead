# etchhead

Etch filesystem head paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/etchhead/

## Install / run

```bash
git clone https://github.com/theworker02/etchhead.git
cd etchhead
node src/cli.js
node --test
```
